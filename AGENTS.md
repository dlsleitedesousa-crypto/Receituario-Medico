# Histórico das alterações do site

O usuário solicita que todas as alterações de código e arquivos do site sejam registradas no GitHub, no repositório `dlsleitedesousa-crypto/Receituario-Medico`.

- Trabalhe neste repositório e registre cada alteração concluída em um commit com mensagem clara, após as verificações adequadas.
- Envie os commits ao remoto `origin` quando houver autenticação disponível. Caso o envio falhe, informe que o registro está apenas local e explique o impedimento.
- Antes de publicar uma alteração na Hostinger, confirme que o código correspondente foi enviado ao GitHub. Não publique alterações com envio pendente.
- Não inclua credenciais, `api/config.local.php`, dados pessoais ou exportações do banco nos commits. Preserve a configuração privada do servidor durante publicações.
- Alterações feitas diretamente na Hostinger não são sincronizadas automaticamente para o GitHub. Quando solicitado a recuperar essas alterações, compare os arquivos do servidor com o repositório e versione a cópia sem segredos.
- O histórico solicitado se refere ao código e aos arquivos do site; não versione cadastros, logotipos ou outros dados de usuários armazenados no MySQL.
